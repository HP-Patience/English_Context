# 多用户学习数据的归属边界

ContextVocab 从当前固定单用户使用扩展为多人使用时，保留现有固定用户的学习数据并将其归属于唯一管理员本人；新增朋友账号从空白个人学习数据开始。单词、词义、词表分组和已发布故事课程属于公共内容，而普通学习、复习、故事进度、收藏、目标、个性化设置及离线内容属于个人学习数据。管理员可以直接控制汇总统计的开放范围，但默认不读取详细学习记录或敏感配置。账号删除会在二次确认后永久删除该账号及其个人学习数据，不影响公共内容。当前互动范围限制在管理员与其朋友账号之间，规划包含打卡、五维排行榜、单一共同挑战、异步消息与固定鼓励、以及不影响正式掌握度的单词小测验。这个边界优先保证既有数据连续性和账号隔离，并为后续学习互动保留空间。
